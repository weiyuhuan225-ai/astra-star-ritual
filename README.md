# 星契 ASTRA

**让漫天星辰，为你一人汇聚。**

[在线体验](https://weiyuhuan225-ai.github.io/astra-star-ritual/)

输入出生日期、时间与城市，体验星辰汇聚、法阵成形与结果卡揭晓，再探索本命星图并保存个人星印卡。

- 太阳、月亮、上升与行星落点；自我、关系、成长三个解读栏目。
- 约 8 秒的星辰汇聚仪式，可跳过、重播或减少动态。
- 可编辑称呼与主题语的深浅色星印卡，支持高清 PNG 导出。
- 无需账户；计算与收藏在当前设备完成；单文件 HTML 可离线打开。
- 首页“先体验一次星辰汇聚”使用虚构示例。

解读用于娱乐与自我探索。出生时间未知时，不生成上升与宫位。
